# E-Commerce Sales Analysis

## Project Overview
This project focuses on cleaning, analysing and visualizing an e-commerce sales dataset using Microsoft Excel.

## Objectives
- Clean and prepare the sales data
- Handle missing and inconsistent data
- Combine tables using VLOOKUP
- Perform statistical analysis
- Create Pivot Tables
- Create charts and an interactive dashboard
- Identify key sales insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- VLOOKUP
- Charts and Dashboard

## Dataset
The dataset contains customer, product, store and sales transaction information.

## Data Cleaning
- Removed records with missing required values
- Checked for duplicate Sales IDs
- Corrected inconsistent Product IDs
- Validated Total Amount calculations
- Prepared the data for analysis

## Analysis
The analysis includes:
- Total Sales
- Average Sales
- Median Sales
- Mode
- Standard Deviation
- Total Quantity Sold
- Number of Orders
- High Value Orders

## Visualization
The dashboard contains:
- Sales by Category
- Sales by Region
- Sales Distribution by Category

## Key Findings
- Sports generated the highest sales.
- Beauty generated the lowest sales.
- Total sales were approximately ₹2.15 million.
- 886 orders were above ₹1,000.

## Conclusion
The cleaned and transformed data was used to generate meaningful sales insights through Pivot Tables, charts and a dashboard.
